# Appalachia Dermatology Workforce Study

**Dermatologist Access Disparities and Melanoma Outcomes in Appalachian Versus Non-Appalachian US Counties**

Public research archive for a county-level ecological analysis of dermatologist access and melanoma mortality.

## Research files

All source data, the frozen analytic workbook, original exploratory notebook, reconstructed NPPES filter, and validation scripts are in [Appalachia_Dermatology_Repository](./Appalachia_Dermatology_Repository/README.md).

## Validated workforce findings

25,392 ZIP-level dermatologists; 25,358 county-allocated dermatologists; 3,235 counties (423 Appalachian). Dermatologist density was 4.79 per 100,000 in Appalachia versus 7.67 per 100,000 outside Appalachia. Counties without dermatologists numbered 186 and 1,358, respectively.

## Melanoma mortality

The 99th-percentile-filtered, complete-case Pearson association was approximately r = -0.24 (p < 0.001). The full study folder includes a validation script and documents substantial suppression of county-level mortality data.

## Limitations

The original exploratory notebook is not guaranteed to run sequentially. The original ARC source file and exact NPPES release were not independently verified; the NPPES extraction script is explicitly reconstructed. See the study folder README for details.
