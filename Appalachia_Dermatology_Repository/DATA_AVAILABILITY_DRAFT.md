# Data and code availability (draft for manuscript)

The analytic dataset, original exploratory notebook, validation scripts, and supporting data files are available in the public GitHub repository at https://github.com/victorlufi/Appalachia-Dermatology-Workforce/tree/main/Appalachia_Dermatology_Repository . Underlying public sources include NPPES, the US Census Bureau, HUD USPS ZIP-to-county crosswalk, Appalachian Regional Commission, and NCI State Cancer Profiles. The NPPES extraction script is reconstructed rather than the verified original. Source provenance and remaining limitations are described in README.md.
