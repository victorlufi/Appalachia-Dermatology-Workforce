# Data and code availability (manuscript draft)

The analytic dataset, original exploratory notebook, validation scripts, and supporting data files are publicly available in the GitHub repository (https://github.com/victorlufi/Appalachia-Dermatology-Workforce) and archived in Zenodo (version v1.0.1, https://doi.org/10.5281/zenodo.23576584). Original source data were obtained from the National Plan and Provider Enumeration System, US Census Bureau, US Department of Housing and Urban Development, Appalachian Regional Commission, and National Cancer Institute State Cancer Profiles. The NPPES filtering script was reconstructed for documentation and has not been verified against the original release. Data provenance, preprocessing, and reproducibility limitations are detailed in the repository README.

**Version-specific DOI for manuscript citation:** https://doi.org/10.5281/zenodo.23576584

**Concept DOI (all versions):** https://doi.org/10.5281/zenodo.23576583
